Roadmap: what is built and what is planned

Three labels are used here and nowhere else on the site. Built means it works on a laptop with demo data. Partly built means some pieces exist. Planned means it is not started or it needs hardware I do not have.

Last changed 2026-10-28

Built, on demo data

These work in the interface on a laptop. None has run on a Pi or on the water.

Partly built

  • Fish ID: the model is trained and tested on a laptop at 82.1% top-1. It is not on a Pi, there is no camera program, and the demo has no photo screen.
  • Voice: the speech service is written. Speech models, microphone capture and playback are not installed or written. Typed questions work.
  • Map data: the pack builder can use NOAA BlueTopo depth, but I have not built and checked a real depth pack for my first area.
  • Heat map layer: it exists. I have not tested whether it is useful.

Planned, needs hardware or a decision

  1. Buy the Pi 5, a 7 inch display with dimming, a GPS receiver and a power bank.
  2. Write the settings file for real hardware and turn off the fake drivers.
  3. Run the Pi checks: boot time, power loss, heat and brightness in sun, runtime, hotspot, read-only root.
  4. Do a dock test, then a short trip, with the backup phone and printed regulations.
  5. Add a water temperature probe and a pressure sensor, and write their drivers.
  6. Add an LTE modem, so forecasts and alerts work away from Wi-Fi.
  7. Decide on a sonar. I do not own one and the choice is open.
  8. Build the Pico 2 co-processor firmware for safe shutdown, battery gauge and buttons.
  9. Install speech-to-text and text-to-speech, and choose whether to use a language model at all.
  10. Write the camera program and a photo screen for fish ID.
  11. Verify the Virginia regulation table, species values and place lists against official sources.
  12. Check the bite weights against my own catch log once it holds about 100 trips.

Not planned

  • Anything that claims to be for navigation.
  • A release of the fish ID model for commercial use. It is non-commercial by its training data. The application code stays private for now.

How this page is kept honest

The text on this site is written by hand, and I change a page's "last changed" date only when I change its facts. Screenshots are the exception: they are captured automatically from the interface each time I publish, so they always match the current demo build.

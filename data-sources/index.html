Data sources and credits

Almost everything this project knows comes from public data and open-source software that other people built. This page says what is used where, and under what terms I could find.

Last changed 2026-10-28

How to read this page

"In the app" means a source the device fetches or ships in a pack. "Research" means I used it once, on my laptop, to test the bite score. I list the terms I found for each source. Where I found none, I say so. If you run a source listed here and want a credit changed, open an issue on the GitHub project page.

Open-source software and design

  • MapLibre GL JS (BSD-3-Clause) draws the map, and PMTiles reads the map tile file.
  • Svelte 5 and Bits UI (MIT) build the interface. Vite builds it.
  • Manrope (SIL Open Font Licence 1.1) is the interface font and the font on this site.
  • Weather, wind and moon icons are from Meteocons by Bas Milius (MIT). The other icons are my own drawings.
  • The bite score started from the logic in fishin by Steve Wasko (MIT), https://github.com/sjwasko/fishin. Most of its weights have since been replaced. The code was re-implemented, not copied.
  • The question matcher uses hassil (Apache-2.0). The shape of some sentence patterns follows the Home Assistant intents corpus, CC BY 4.0, Open Home Foundation and contributors. Nothing from the corpus is copied unchanged.
  • The fish identifier uses EfficientNet-B0 weights from the timm library, ONNX Runtime and Pillow.
  • Speech uses whisper.cpp (MIT) and Piper, once installed.
  • This site is built with Astro. Charts are drawn at build time.

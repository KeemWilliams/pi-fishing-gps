Offline fishing map with depth charts

The map is a MapLibre vector map that runs from files on the Pi. It shows depth as colour bands, contour lines and numbers, and it carries a Not for navigation notice at the bottom of the screen.

Built Works on demo data. No real depth pack has been used on the water. · Last changed 2026-10-28

Everything on this page is demo data

The river and bay in these screenshots are made up. The centreline is hand placed, the widths and depths are invented, and the screen says "Demo map, not for navigation" in a corner. I use a fake river so that nothing on this public site can be mistaken for a chart of a real place.

How the map works offline

The map is drawn by MapLibre GL JS inside a Svelte 5 interface. The base map is a vector tile file in the PMTiles format, cut from OpenStreetMap data for the area I fish. The Pi serves that file to the browser from its own disk, so panning and zooming need no network.

Map data comes in packs. A pack is built on a laptop: base map tiles, places such as ramps and piers, depth data, species information and the rules files. The builder signs the pack with a key that never leaves the laptop, and the Pi refuses any pack that is unsigned or edited. That matters because a tampered pack could make the device state a wrong fishing limit as if it were a fact.

Depth

Depth is drawn three ways at once: colour bands from pale (shallow) to dark blue (deep), contour lines, and whole-foot numbers that appear as you zoom in. The legend says "Depth in feet, datum unknown", and the assistant is written to say "no charted depth" if a pack has none.

The pack builder can take real depth from NOAA BlueTopo, which is public chart data in the CC0 licence class. It treats BlueTopo as chart data and not as a navigation product. A pack without depth is allowed, and so is a clearly labelled synthetic one for tests. A real depth pack for my first area, checked against the water, is on the roadmap and not done.

Layers and chips

A row of chips along the top turns layers on and off: Depth, Current, Wind, Heat map, Spots and Ramps. Current arrows and the wind compass have their own pages. Spots and ramps come from state boating access data, OpenStreetMap and a short list I curate by hand. Entries I have not visited or checked are marked as unverified in the app.

The Heat map layer shows reported fish movement and satellite sea temperature. It exists, but I have not tested whether it helps, so I do not make any claim for it here.

Day, night and bright sun

The interface has three looks. Day is a bright glass theme. Night is a deep navy theme with light numbers. Bright sun raises contrast, draws outlines in place of shadows and makes the secondary text darker, because shadows vanish in glare. Whether the sun mode is readable on a real panel outdoors is on the list of things to test.

On a phone

A phone that joins the Pi's Wi-Fi gets the same map in a narrow layout, with a tab bar at the bottom.

What is not done

  • Map labels use a glyph set that covers the Latin letters only, and I have not checked place names in the area I fish.
  • Packs have not been built with real depth for a real area and compared with what I see on the water.
  • Nothing here has run on a Pi, so smooth panning on the Pi's own display is unproven.

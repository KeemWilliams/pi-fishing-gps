Hardware for a Raspberry Pi 5 fishing GPS

The software runs on a laptop with fake sensors. This page describes the hardware it is written for and what I still have to buy and prove.

Planned Nothing is bought or tested yet. · Last changed 2026-10-28

The target

The design target is a Raspberry Pi 5 with a 7 inch touch display at 1024 by 600, which is the size the interface is laid out for. The display needs software dimming, because a screen that is readable in sun but cannot be turned down is a problem at dawn and at night. A phone can join the Pi's own Wi-Fi network and use the same interface, so the phone layout is a first-class screen and not an afterthought.

For the first trips I plan a field kit rather than a sealed handheld: the Pi in a dry bag, a USB-C power bank, the display and a buzzer. The sealed handheld case exists as a design on paper and as a list of questions about heat, sun and salt. I have not built any of it.

What runs without the hardware

The Pi services have fake and replay drivers, so the whole interface runs on a laptop. Every screenshot on this site comes from that setup, using invented demo data. At my last check the shipped defaults still used fake GPS and fake sensors, so the first software job before a real trip is a settings file for the real hardware. The interface is meant to say "no reading" when a sensor is missing instead of showing a number, and that is one of the things to prove on the bench.

What has to be proven on a Pi

Several things can only be answered by the real hardware, and none of them has been tested:

  • Boot to a working map, outdoors, with a GPS fix, in under two minutes.
  • Power loss during a write, repeated many times, with the database intact afterwards.
  • Heat and brightness in direct sun at 30 degrees C or warmer.
  • Runtime on a power bank. The design target is eight hours, and the first test is four.
  • The Wi-Fi hotspot, the firewall rules and the read-only root file system. The configuration is written but untested.

I will write up the results here after the first dock test and the first short trip. Until then the roadmap marks each of these as planned.
